# Halune — Feedback & public roadmap

[Halune](https://halune.github.io/) is a private, serverless baby monitor for
Android: two phones, your WiFi, no cloud, no account, no data collected.

This repository holds the **public roadmap** and collects **your feedback** —
no source code here.

## How to vote

Each roadmap idea is an issue. Add a 👍 reaction to the ones you want first —
[the issue list sorted by votes](https://github.com/halune/feedback/issues?q=is%3Aissue+is%3Aopen+sort%3Areactions-%2B1-desc)
is the live scoreboard. Comments about your setup and use cases are even more
valuable than votes.

## Bugs & ideas

Open a new issue for anything: bug report, feature request, question.
Every single one gets read. You can also write to halune.app@gmail.com.

*No promises, no dates: items ship when they're ready, in the order you set.*
